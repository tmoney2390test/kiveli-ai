# Bounded dialogue routing continuity

Applies to direct and private AI group dialogue. When the current preference,
adult policy, participant age, relationship and provider rollout allow adult
dialogue, clearly suggestive wording now uses the existing adult route without
requiring explicit anatomy. Ordinary affection and ambiguous everyday phrases
keep normal routing. This classifier is routing evidence, not consent or a
change to authored character boundaries.

Each new user message still runs input moderation and content classification.
Its existing server-written `provider_metadata.adultRouting` records only
version, eligibility, fresh classification evidence, and whether continuity
must reset. It contains no prompt, provider credentials or media URLs.

After a fresh adult classification, the next **three user turns** stay on the
adult route. Fresh adult/suggestive input renews that window. Assistant output,
context-only classification, carryover itself and retries never renew it.
Existing contextual continuation classification still works independently:
genuinely ongoing adult content may continue beyond three turns.

The history loader reads at most three user-message metadata records, scoped
by authenticated user and the already-owned conversation. It does not import
another conversation's history or disclose additional history to group
speakers. A whole group turn uses one frozen history; five assistant speakers
do not consume five user turns. Retries use the original message sequence.

Stop/withdrawal, an explicit topic reset, an ineligible turn, or an unknown
legacy record interrupts the carryover. Every actual speaker still has their
policy and relationship eligibility checked. Feature disablement and a
non-explicit preference override carryover immediately. Photo requests do not
seed carryover and retain their existing media route and access controls.

Current classification remains separate from the route:
`routeReason=adult_context_carryover` identifies a continuity choice. The prompt
explicitly says that provider continuity must not escalate a neutral message.
Provider selection, owner-only Venice/WaveSpeed experiments, existing fallback
rules, moderation and visual/native restrictions are otherwise unchanged.
No new classification LLM calls, provider retries, rates or credits are added.

Context quotes use the same history and saved content preference. Routing
version is part of quote authorization, invalidating pre-release quotes rather
than silently billing a different route. Missing history produces a retryable
error, not an unannounced provider switch.

## Release

No migration, transcript rewrite, backfill or frontend/native rebuild is
required. Legacy messages do not seed the new window: it starts with the next
fresh classified adult/suggestive request after deployment. Do not modify the
historical migration ledger for this change.

Run domain tests, routing/history Deno tests, existing private-policy and chat
experiment tests, lint, typechecks and the normal CI web build. Trace relative
imports and deploy all affected Edge Function consumers, preserving their
authentication configuration and secrets. Record deployed function versions.
Rollback by redeploying the prior commit; additional metadata is inert for old
code. Routing version must change whenever carryover semantics change.

Controlled tests use classifications and non-graphic fixtures. No paid dialogue
quality evaluation or production-user messages are generated by these tests.
